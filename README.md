## Project Overview

ShadowRunner is a 3D side-scrolling parkour game.  The player keeps running to reach the portal by precisely jumping, switching gravity, and changing their own color.

## Chosen Platform

Unity was selected for its robust support for cross-platform 3D development. It is a powerful game engine that accelerates game development. It has an asset store that provides free licensed assets and as well as a learning platform with plenty of learning materials.

## How to Build the Application

1. **Install Unity Hub**  
   Download and install [Unity Hub](https://unity.com/download) to manage Unity versions and projects.

2. **Install a Compatible Unity Version**  
   - This project was developed with Unity version **2022.3.57f1**.  
   - In Unity Hub, install the matching Unity Editor version.

3. **Clone the Repository**  
   ```bash
   git clone https://github.com/RongliangZhang456/ShadowRunner.git
   ```
   Or download as ZIP and extract.

4. **Open the Project in Unity**  
   - Launch Unity Hub.
   - Click **Add** to add the `ShadowRunner` folder.
   - Open the project.

5. **Run the Application in the Editor**  
   - In the Unity Editor, open the main scene (located in `Assets/Scenes/`).
   - Press the **Play** button to run the application in the editor.

## Difficulties During Development with the Platform/IDE
- **Learning Curve:** While Unity is easy to start with, mastering advanced techniques like shader programming and lighting requires significant additional learning.

- **Version Control:**  We chose Git and GitHub for version control instead of Unity's own tool and platform. It turned out to be a bad choice because conflicts caused by changes made in the game scenes are almost impossible to resolve.
